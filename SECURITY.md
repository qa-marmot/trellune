# Security policy

Please do not open a public issue for a suspected vulnerability, credential,
privacy exposure, or learner-data concern. Use GitHub's private security
advisory flow for this repository, or contact the repository owner privately.

Reports should include a minimal reproduction, affected version, impact, and
whether any personal learning data could be exposed. Do not include production
tokens, Access assertions, raw exports, or learner content.

For architecture and operational controls, see
[`docs/SECURITY.md`](docs/SECURITY.md). The project validates external data
strictly, keeps AI interaction manual, and treats backups, clipboard text, and
remote sync as untrusted boundaries.
