# Naming decision

## Decision

- Previous public name: **English OS**
- New canonical name: **Trellune**
- Pronunciation: **TREH-loon**
- Recommended public GitHub slug: `trellune`
- Product position: a local-first, structured language-learning practice loop.

Trellune is a coined name inspired by a trellis: a light structure that supports
steady growth without prescribing a single path. It is intentionally not tied to
an AI provider, English alone, or an operating-system metaphor.

## Principles

The name needed to be short, pronounceable for Japanese and English speakers,
memorable, suitable for a repository and wordmark, and broad enough for a
privacy-oriented learning product. Names centred on `AI`, a named provider,
`OS`, generic `Learn English`, or a difficult random string were excluded.

## Screening

Twenty internal candidates were generated. The first screen used current general
web search, GitHub repository search, npm package search, app/product search and
exact-name domain lookup where available. It is an obvious-collision screen, not
a trademark search or a statement that any domain is available.

| Finalist | Pronunciation | Score / 100 | Finding                                                                                                                                                      | Decision     |
| -------- | ------------- | ----------: | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------ |
| Trellune | TREH-loon     |          90 | No obvious same-industry product or public GitHub/npm package found. An exact-match domain appears claimed or unavailable, so no availability claim is made. | **Selected** |
| Syllora  | SIL-or-a      |          79 | A similarly named active organisation appeared in search results.                                                                                            | Rejected     |
| Kaelume  | KAY-loom      |          77 | Sparse unrelated personal-use results; weaker learning connection.                                                                                           | Rejected     |
| Cadensa  | kuh-DEN-suh   |          66 | Active software products in other categories.                                                                                                                | Rejected     |
| Parlora  | par-LOR-uh    |          42 | Active language-learning and conversation products.                                                                                                          | Rejected     |

Other screened directions included Cadence, Lexovia, Lingora, LumaLoop,
Relyra, Rivora, Syllune, Verluna, Voxora, Vocabra, Wordloom, Talktide,
Phraseway, Recalio and Lerniva. They were removed for genericness, weak
pronunciation, or an obvious product/software collision.
