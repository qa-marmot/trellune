# ChatGPT manual acceptance

Status: **manually tested** through Trellune's copy/paste workflow.

1. Open a normal text chat and paste the Trellune request for Days 1, 90, 180,
   or 365.
2. Send the text first; begin Voice only after the lesson context is present.
3. Keep the conversation inside the stated Core/Boost boundary.
4. Ask explicitly for `SESSION_JSON` after the conversation.
5. Paste it into Trellune, confirm strict preview validation, and save only after
   reviewing the import.

This does not claim that every current ChatGPT UI, subscription, Voice mode, or
Project feature behaves identically. It is not an API integration.
