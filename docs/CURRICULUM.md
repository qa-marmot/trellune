# 365日Coreカリキュラム

## Stage Assessment境界

bundleはDay 1〜365を保持し、migration `0012`を適用したserver ACTIVEは365になる。Foundation、Independent、Fluency、B2 Challengeは`ASSESSMENT_JSON` 1.0で別々に評価する。attemptは選択されたskillの証跡であり、カリキュラム完了イベントではない。未実施、`provisional`、`reinforcement-recommended`のいずれもCoreをlockしない。Day完了やAssessmentの`pass`だけでCEFRを正式認定しない。現行GraduationのB1+ / B2-entry / B2はReading、Writing、Listening、spoken interaction/productionを含む8技能の直接証跡による推定であり、B2-entryは全skill 3/5以上、B2は`pass`かつ全skill 4/5以上を必要とする。弱いmodeを平均で隠さず、certificationとは扱わない。

## 目的と進行原則

日本語母語の学習者が365個のCore学習日を通じて、A1からB2入口へ挑戦し、身近な話題や一般的な論点で15〜25分の会話をより少ない支援で維持できることを目指す。カリキュラム日は暦日ではなくCoreの進行番号である。欠席しても翌日に先へ飛ばず、未完了の日から再開する。

Coreは次の全条件を満たしたときだけ、その日を完了とする。

1. そのCore開始時点で必須に確定した期限復習を全件完了
2. 当日の文法教材と文法課題を完了
3. 当日のCore Voiceを実施し、検証済みのCoreセッションJSONを取込

連続学習日数は利用者のローカル日付でCoreを完了した日だけを数える。Boost、Study Mode、週次評価だけでは増えない。Boostはカリキュラム日を進めず、未来のCoreを完了しない。

## 到達目標

- 身近な話題で約10分、質問・回答・追加質問を使って会話する
- 基本文法を会話の中で選択する
- Coreで630語（原則7語/日）に触れ、能動語彙600〜800語を目標にする
- Coreで180定型表現（原則2個/日）に触れ、少なくとも150個を使用する
- 過去・現在・未来を行き来して説明する
- 聞き返し、説明、言い換え、誤解修復、話題転換を行う

新規取得の全経路合計はローカル日ごとに単語8語、定型表現3個まで。Coreは原則7語・2表現なので残りをBoostに使える。上限を使い切っても既習項目の復習・会話は継続できる。

## 日別データの正本

UIが使用する正本は `src/data/curriculum.ts` の `CURRICULUM` である。Day 1〜90は凍結済み配列をそのまま保持し、Day 91〜180は`src/data/independent/`、Day 181〜270は`src/data/fluency/`、Day 271〜365は`src/data/b2Challenge/`のUnit別ファイルで管理する。各要素は `day`, `week`, `phase`, `theme`, `objective`, `grammar`, `vocabulary`, `phrases`, `voiceTask` を持つ。ChatGPT Projectの `03-curriculum.md` はChatGPT利用者向けの説明要約で、プロバイダにかかわらず衝突時はアプリから生成した当日プロンプトを優先する。

拡張基盤では `SUPPORTED_CURRICULUM_DAY_MAX=540`、`AVAILABLE_CURRICULUM_TOTAL_DAYS=365`、migration `0012`適用後のD1 `activeTotalDays=365`を別概念として扱う。常に`ACTIVE <= AVAILABLE <= SUPPORTED`を守る。Manifest／Stage／Unit／Lessonはリリース済みDay 1〜270を内容・順番とも変更せず包み、永続化IDとは別の決定的lesson IDを提供する。Day 270完了者は既存Core証跡からDay 271を導出し、既存progress/profileを一括更新せず、Day 271 rowは実学習開始時だけ作る。Day 366以降は構造上540まで対応していてもbusiness inputとして拒否する。

## 文法の導入と再使用

文法は「短い意味説明 → 肯定例 → 疑問または否定 → 制御練習 → Voiceでの使用」の順で扱う。初出後も別場面で再使用する。文法課題は正答だけでなく、誤答への説明を確認し再回答した時点で完了とする。未来文法をBoostで扱った場合は `previewed` のままとし、正規のCore日に教材・課題・Voiceを再度行う。

## 評価

Voiceでは task completion、grammar、vocabulary、fluency、interaction を各1〜5で評価する。数値だけでCoreを不合格にしない。JSONの正常取込と必須活動の実施が完了条件であり、低得点項目は復習カード、間違いノート、Boost推奨に回す。週次評価は診断であり、Core進行を直接変更しない。
