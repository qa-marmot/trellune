# Trellune launch copy

## Short description

Trellune is a local-first 365-day English learning PWA with spaced retrieval,
authored practice, and a bring-your-own conversation-AI bridge. It does not
require an AI API key.

## X / project showcase

Trellune is now open source: a local-first 365-day English learning PWA with
spaced retrieval, reading/writing practice, offline support, and a manual
conversation-AI bridge. Learning data stays in your browser by default; no AI
API key is required. Try the synthetic demo or run it locally.

## Show HN

**Show HN: Trellune – a local-first 365-day English learning PWA with no AI API
key requirement**

Trellune combines review scheduling, grammar transfer, productive vocabulary,
reading/writing labs, and a manual copy/paste bridge to the conversation AI a
learner already uses. It validates returned `SESSION_JSON` locally rather than
integrating provider APIs. The public demo uses only synthetic, resettable local
data; optional sync is self-hosted. Completing the curriculum is not a CEFR
certification.
