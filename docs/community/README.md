# Community and launch materials

These files help a maintainer or community member describe Trellune accurately
without overstating its capabilities. They are drafts for human posting and do
not authorize automated posting or cross-posting.

- [Positioning](POSITIONING.md): one-sentence, three-sentence, and long-form
  descriptions.
- [Show HN](SHOW_HN.md): title options and an honest launch post.
- [Reddit](REDDIT.md): adaptation notes and a non-spam posting order.
- [Social](SOCIAL.md): English and Japanese short posts.
- [Japanese technical article](JAPANESE_TECH_LAUNCH.md): Qiita/Zenn outline.
- [Maintainer policy](MAINTAINER_POLICY.md): lightweight community expectations.
- [Screenshot evidence](SCREENSHOTS.md): safe, reproducible README images.

Use [GitHub Discussions](https://github.com/qa-marmot/trellune/discussions) for
questions and ideas. Use Issues for specific, actionable work.
