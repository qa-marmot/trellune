## English

Trellune is now open source: a local-first 365-day English-learning PWA with
spaced retrieval, grammar/vocabulary production, reading/writing, feedback and
retry, and a manual bridge to the conversation AI you already use.

No AI API key. No provider automation. The public demo uses resettable synthetic
data only.

Demo: https://trellune-demo.pages.dev
Source: https://github.com/qa-marmot/trellune
