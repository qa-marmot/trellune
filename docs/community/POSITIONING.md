# Trellune positioning

## One sentence

Trellune is a local-first 365-day English-learning PWA that combines spaced
retrieval and structured practice with the conversation AI a learner already
uses—without an AI API key.

## Three sentences

Trellune gives independent learners a deliberate daily loop: review, grammar
and vocabulary production, scheduled reading/writing, feedback and retry, then
an optional manual conversation bridge. Learning data stays in the browser by
default; optional sync is self-hosted. It does not automate ChatGPT, Claude,
Gemini, or any other provider, and Day 365 completion is not a CEFR certificate.

## Longer description

Many AI language tools begin and end with an open chat box. Trellune puts the
learning system around the conversation instead: a 365-day curriculum, spaced
retrieval, bounded grammar and vocabulary practice, authored reading/writing
labs, feedback and retry, assessment, and a local learning history. A learner
can copy a structured request into the conversation AI they already use and
paste a strict `SESSION_JSON` result back into Trellune. There is no provider
API key, no provider browser automation, and no claim that completing the path
is a formal CEFR credential.
